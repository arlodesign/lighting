Lights

MiniLab 3 + laptop + 8 lights · Quick start

1Connect

  1. Lights: power on, DMX cable daisy-chained, first light's DMX IN.
  2. Open DMX dongle → laptop USB (straight in, no hub).
  3. MiniLab → laptop USB.
  4. Quit QLC+ and any other lighting app.

2Start

cd lighting
npm start

Open localhost:4000. Both dots at the bottom should be green: MiniLab and Lights.

3Play

Big knob Turn to scroll the setlist, click to load the song.
White keys Pick a look, calm (left) → frantic (right). Hit harder = brighter. Black keys do nothing.
Pads 1–8 Strobe (press harder = faster) · White flash · Blackout · Color bump · Left flash · Right flash · Lightning · Tap tempo. Hits last as long as you hold.
Knobs 1–8 Speed · Hue · Color · Palette · Width · Fade · Shape · Variety (one color → many)
Faders 1–4 Master · Energy (bottom verse, middle song, top chorus) · Balance (left ↔ right) · Audio (lights pulse with the band)
Touch strips Left: slide a spotlight across the stage. Right: swell brightness.
Laptop Backup for everything: space tap · esc blackout · S strobe · F flash · L lightning · 1–9 looks · ↑↓ enter setlist. Press ? for the list.

4Save a song

  1. Load the song, set it the way you like, tap the tempo.
  2. Press ⌘S. It starts that way next time.

Saves the Energy level you're in: push Energy to the top first to set the chorus. Reset song undoes it. Export setlist downloads all songs for the repo.

5Lights not working?

Look at the display on the back of a light.

  • Blinking (A001): no DMX. Quit QLC+, check cable is in IN, plug dongle in directly, try another cable.
  • Steady but dark: check Master fader and Blackout, then the light's address and 7-channel mode.
  • MiniLab dot red: replug USB. If pads act odd, quit and run npm start -- --no-screen.
Addresses: 1, 11, 21 … 71, house left → right (L1–L4, R1–R4) · Setlist: src/setlist.json · More: README.md
